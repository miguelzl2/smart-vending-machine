🚀 Smart Vending Machine com Arduino & Web AppUm sistema completo e interativo de controlo para uma Máquina de Vendas (Vending Machine), construído com Arduino Mega 2560 e integração em tempo real com uma Aplicação Web (via Web Serial API).📌 Sobre o ProjetoEste projeto simula a eletrónica e a mecânica de uma máquina de vendas automática. O utilizador pode navegar por um menu de produtos num Ecrã LCD utilizando um teclado analógico físico ou, em alternativa, controlar a máquina diretamente a partir do computador utilizando uma aplicação Web dedicada. Quando um produto é selecionado, o sistema aciona um motor de passo para efetuar a entrega (girando a espiral).✨ Principais FuncionalidadesMenu Interativo: Navegação fluida com botões (Subir, Descer e Confirmar).Display Visual: Ecrã LCD 20x4 I2C para apresentar o estado do sistema e os produtos.Sistema Anti-Bouncing: Código otimizado para evitar múltiplos cliques acidentais nos botões analógicos.Controlo de Motor: Acionamento preciso de um motor de passo para simular a queda do produto (1 rotação completa por compra).Interface Web (Gêmeo Digital): Uma App em HTML/JS que se liga ao Arduino por USB usando a Web Serial API, permitindo controlar a máquina e ver animações em tempo real no browser.🛠️ Hardware UtilizadoPlaca Principal: Arduino Mega 2560Interface Visual: Display LCD 20x4 + Módulo I2CNavegação: Teclado Analógico (AD Keypad - 5 botões)Atuador (Espiral): Motor de Passo 28BYJ-48 (5V) + Driver de controlo ULN2003(Futuro) Controlo de Acesso: Leitor RFID RC-522 para "pagamento" ou desbloqueio por aproximação.🔌 Esquema de Ligações (Pinout)Certifique-se de fazer as ligações com o Arduino desligado da energia.ComponentePino do ComponentePino do Arduino Mega 2560Ecrã LCD (I2C)SDAPino 20 (SDA)SCLPino 21 (SCL)VCC / GND5V / GNDTeclado AnalógicoOUT (Sinal)A0 (Analógico)VCC / GND5V / GNDDriver ULN2003IN1Pino Digital 4(Motor de Passo)IN2Pino Digital 5IN3Pino Digital 6IN4Pino Digital 7VCC (+) / GND (-)5V / GND💻 Como Executar o Projeto1. Configurar o ArduinoAbra a IDE do Arduino.Certifique-se de que tem as bibliotecas instaladas: LiquidCrystal_I2C (para o ecrã) e Stepper (já nativa no Arduino).Faça o upload do código .ino para o seu Arduino Mega.Nota: Se o ecrã LCD mostrar apenas blocos brancos, ajuste o potenciómetro na parte traseira do módulo I2C ou altere o endereço no código de 0x27 para 0x3F.2. Utilizar a Web AppFeche o Arduino IDE (para libertar a comunicação da porta COM).Abra o ficheiro app.html num navegador compatível com Web Serial (recomendado: Google Chrome ou Microsoft Edge).Clique no botão "Desligado" (ícone USB) no topo da página.Selecione a porta COM do seu Arduino na janela que aparecer.Use os botões na página web para controlar a máquina física e veja a magia acontecer!🚀 Próximos Passos (Roadmap)[ ] Implementar sistema de pagamento/validação com Leitor RFID RC-522.[ ] Substituir o motor de passo de 5V por um motor DC de 12V mais robusto, utilizando um Módulo Relé ou driver L298N (com fonte externa).[ ] Adicionar sensores de infravermelhos (IR) para confirmar se o produto realmente caiu.Projeto desenvolvido como portfólio de hardware e integração web.
